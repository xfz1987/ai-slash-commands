# 项目名称

Web 应用性能监控与错误追踪后台管理系统（APM & Error Tracking Console）

---

## 项目背景 & 目标

设计一个面向前端与全栈团队的性能监控后台系统，用于：

- 统一管理多个 Web 应用的错误与性能数据
- 快速定位线上问题（错误 / 性能瓶颈）
- 提供错误回溯、报警、分析报告等能力
- 面向不同角色（开发 / 运维 / 管理）提供不同视图

该系统数据来源包括：

- 前端 SDK 上报
- 日志 / 数据中心聚合服务
- 用户行为回放（rrweb）

---

## 核心对象模型（Concepts）

- 应用（Application）
- 环境（Environment）：prod / staging / test
- 错误（Error）
- 性能指标（Performance Metric）
- 报警规则（Alert Rule）
- 用户行为回放（Session Replay）
- 报告（Report）

---

## 全局信息架构（IA）

- 应用列表
- 应用配置
  - 基础信息
  - SDK 接入配置
  - SourceMap 管理
- 错误监控
  - 错误列表
  - 错误详情
  - 用户行为回放
  - 错误治理 & 状态管理
  - 报警规则
- 性能监控
  - 核心性能指标概览
  - 页面 / 接口性能分析
  - 性能趋势图
  - 性能分析报告
- 报表 & 导出
- 用户 & 权限管理

## 应用配置模块

### 应用基础信息

- 应用名称
- 应用标识（App ID）
- 所属团队
- 环境配置（prod / staging / test）

### SDK 接入配置

- SDK 安装示例代码
- 上报地址
- 采样率设置
- rrweb 开关配置

### SourceMap 管理

- SourceMap 上传
- 版本号关联
- 构建时间
- 自动 / 手动上传说明

---

## 错误监控模块

### 错误列表页

展示前端 SDK 上报的错误聚合列表：

- 错误类型（JS Error / Promise / Resource / Custom）
- 错误摘要
- 影响用户数
- 出现次数
- 最近发生时间
- 当前状态（Open / Acknowledged / Resolved / Ignored）

支持筛选条件：

- 时间范围
- 错误类型
- 页面 URL
- 版本号
- 环境
- 状态

---

### 错误详情页

展示某一类错误的完整信息：

- 错误堆栈（Stack Trace）
- SourceMap 还原后的源代码位置
- 错误首次 / 最近发生时间
- 影响用户列表
- 关联版本 / 页面
- 关联性能指标（如卡顿 / 慢加载）

操作能力：

- 标记状态（已确认 / 已解决 / 忽略）
- 添加备注
- 关联报警规则

---

### 用户行为回放（Session Replay）

- 使用 rrweb 回放用户操作过程
- 支持跳转至错误发生时间点
- 支持播放 / 暂停 / 倍速
- 展示 DOM 变化、点击、输入行为
- 支持多次会话对比

---

### 错误报警 & 治理

报警规则配置能力：

- 按错误类型 / 错误 ID 配置
- 阀值条件（次数 / 影响用户数 / 时间窗口）
- 报警频率限制
- 报警通知渠道：
  - 短信
  - 电话
  - 邮件
  - 企业微信 / Slack / 钉钉
- 报警接收人配置

支持：

- 已解决后自动停止报警
- 错误恢复通知

---

## 性能监控模块

### 性能概览页

展示核心 Web 性能指标（Web Vitals）：

- LCP
- FID / INP
- CLS
- TTFB
- 首屏渲染时间

支持：

- 多时间维度切换
- 环境对比
- 版本对比

---

### 页面 & 接口性能分析

- 页面加载耗时排行
- 慢页面分析
- 接口请求耗时分布
- 资源加载瀑布图（简化版）

---

### 性能趋势 & 对比分析

- 折线图 / 柱状图
- 版本前后性能对比
- 性能劣化自动标记

---

### 性能分析报告

支持生成指定时间范围内的性能报告：

- 性能指标总结
- 问题页面列表
- 性能趋势解读
- 优化建议（可由 AI 自动生成）

支持：

- 导出 PDF / Markdown
- 邮件发送
- 定期自动生成

---
